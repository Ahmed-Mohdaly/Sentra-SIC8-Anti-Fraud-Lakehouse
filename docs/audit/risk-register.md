| **RSK-04** | **HIGH** | **Reliability / Operations** | **Fargate Regional vCPU Quota Bottleneck (2.0 vCPU Limit)** | Service event log on `sic-kafka-connect-service`: `The reason for failure is You've reached the limit on the number of vCPUs you can run concurrently`. | Baseline services consume 1.5 vCPUs. Rolling deployments or concurrent batch tasks trigger ECS launch failures. | **High** | Submit AWS Service Quota request to increase Fargate vCPUs from 2.0 to 8.0+ in `eu-west-3`. | Small (Admin) | High |
| **RSK-05** | **MEDIUM** | **Reliability / Storage** | **PostgreSQL WAL accumulation risk if Debezium connector stops** | Parameter group `synthetic-pg18-cdc` has `rds.logical_replication=1`. | **RSK-06** | **MEDIUM** | **Correctness** | **REST API `/transactions` returns stale relational data** | `src/synthetic_streaming/api.py:262` queries `db.query(TransactionModel)`. | **RSK-10** | **LOW** | **Correctness / Lineage** | **Batch reference extraction appends files rather than atomic snapshot replacement** | `batch_reference_extractor.py:207-210` names files `{dataset}_snapshot_{timestamp}.parquet` under `snapshot_date=YYYY-MM-DD/`. | If triggered multiple times in one day, partition directory contains multiple snapshot files.
