# Historical data flow and limitations

IBM/Kaggle `credit_card_transactions-ibm_v2.csv` and companion users/cards/MCC/city raw CSV (S3 path confirmed in prior AWS metadata inspection). Read as historical batch, not 2026 live stream. Source timestamps local timezone unknown; retain `TIMESTAMP_NTZ` and source components, not assumed UTC. Preserve signed USD monetary values including refunds. Generate no new historical business IDs just for repo restructuring: keep IDs from executed notebooks and identity checks. `User,Card` composite is source-local card identity. The source `Is Fraud?` is **ground truth** isolated in `workspace.sic8_silver.historical_ground_truth` (count user-provided, not rechecked here), not a detector feature or real bank verified fraud. City centroids approximate, not exact GPS; `Chip -> ATM` is a project assumption that belongs in origin metadata. No historical terminal failure inference.
