# Databricks integration

Cloud access is not implicit just because AWS billing is linked. R4 should verify Unity Catalog Storage Credential, External Location, volume path, read/write grants, DBR version, SQL Warehouse and workload identity. R2 reads 1–10 records and schema before any batch scan. In this repo, `src/r2_spark/spark_jobs.py` is untested (PySpark/Delta missing), and write guard is OFF. No writes to `workspace.sic8_silver` or `workspace.sic8_gold` were performed.
